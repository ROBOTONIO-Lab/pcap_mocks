What is the output of the following code?

def f(v):
    try:
        return 10 // v
    except ZeroDivisionError:

  • 5 zero done done
  • done 5 done zero
  • done done 5 zero
  • 5 done zero done
Έννοια

Το finally εκτελείται πάντα, ακόμα και όταν το try ή το except κάνει return. Τα ορίσματα ενός print υπολογίζονται όλα πριν τυπωθεί οτιδήποτε.

Ανάλυση

Για να τυπώσει το εξωτερικό print, πρέπει πρώτα να υπολογίσει f(2) και f(0). Το f(2): return 5, αλλά πριν φύγει τρέχει το finally → done. Το f(0): ZeroDivisionError → return "zero", και πάλι finally → done. Τέλος τυπώνεται 5 zero.

Γιατί όχι τα άλλα

Το 5 zero δεν μπορεί να βγει πρώτο: το print δεν έχει ακόμα τις τιμές. Τα done δεν εναλλάσσονται με τα αποτελέσματα, γιατί οι δύο κλήσεις τελειώνουν πριν το εξωτερικό print τυπώσει.

Το σκέτο raise μέσα σε except ξαναστέλνει την εξαίρεση. Καθώς η εξαίρεση φεύγει από ένα try, το finally του τρέχει πριν φτάσει στο εξωτερικό except.

Ανάλυση
