Παγίδες ανά θέμα

1.1import — 4 μορφές

  • import math → χρήση math.sqrt. from math import sqrt → σκέτο sqrt. from math import * → όλα σκέτα (κίνδυνος συγκρούσεων).
  • import math as m → υπάρχει μόνο το m. Το math → NameError.
  • from math import sqrt as s → μόνο s, όχι sqrt.
  • dir(math) → λίστα ονομάτων του module. math.__name__ → 'math'.
  • Τα ορίσματα του print υπολογίζονται όλα πριν τυπωθεί οτιδήποτε → μια εξαίρεση στο δεύτερο όρισμα ακυρώνει και το πρώτο.

1.2math — προσοχή στο πρόσημο

  • floor → −∞ · ceil → +∞ · trunc / int() → προς το 0.
  • Θετικοί: floor = trunc. Αρνητικοί: floor(-2.5) = −3 αλλά trunc(-2.5) = −2.
  • sqrt, hypot επιστρέφουν float (hypot(3, 4) → 5.0). factorial(4) → 24.
  • pi, e είναι σταθερές (όχι συναρτήσεις): math.pi, όχι math.pi().

1.2random — ψευδοτυχαίο

  • seed(n) → ίδια ακολουθία κάθε φορά. Χωρίς seed → από το ρολόι.
  • randint(a, b) → και τα δύο άκρα. randrange(a, b) → έως b−1, όπως το range. randrange(1, 10, 3) → 1, 4, 7.
  • random() → float στο [0, 1). choice(seq) → ένα στοιχείο. sample(seq, k) → k διαφορετικά, νέα λίστα. shuffle(list) → επί τόπου, επιστρέφει None.

1.2platform — τι επιστρέφει τι

  • python_version() → '3.12.3' (string). python_version_tuple() → ('3', '12', '3') (tuple από strings).
  • python_implementation() → 'CPython'. system() → 'Windows' / 'Linux'. version() → έκδοση λειτουργικού, όχι Python.
  • machine() → αρχιτεκτονική ('AMD64'). platform() → όλα μαζί σε ένα string.

1.3Δικά μας modules & packages

  • Το import εκτελεί το module, μία φορά. Δεύτερο import = τίποτα.
  • __name__: "__main__" μόνο στο αρχείο που τρέχουμε· στο module είναι το όνομά του.
  • from mod import x αντιγράφει την τρέχουσα τιμή του x. Αλλαγές μετά δεν φαίνονται στο αντίγραφο.
  • Πακέτο = φάκελος με __init__.py (τρέχει στο πρώτο άγγιγμα του πακέτου). import pkg.mod → χρήση pkg.mod.f(), ποτέ σκέτο mod. from pkg import mod → σκέτο mod.f().
  • sys.path: λίστα φακέλων αναζήτησης, πρώτος ο φάκελος του script. __pycache__/.pyc: αυτόματο cache bytecode, όχι κρυπτογράφηση.

1.4pip & PyPI

  • pip install NAME · pip install NAME==1.2.3 (ακριβής έκδοση, διπλό ίσον) · pip install -U NAME = --upgrade.
  • pip show NAME → πληροφορίες (Version, Location). pip list → όλα τα εγκατεστημένα. pip uninstall NAME.
  • pip install -r requirements.txt → από αρχείο. pip --version → έκδοση του pip, όχι του πακέτου.

2.1try / except / else / finally

  • Ροή: try → (except ή else) → finally. Μετά την εξαίρεση, οι υπόλοιπες γραμμές του try παραλείπονται.
  • Τα except ελέγχονται με τη σειρά, εκτελείται μόνο το πρώτο που ταιριάζει. Γονιός πριν από παιδί = το παιδί νεκρός κώδικας.
  • except (A, B): → tuple. Σκέτο except: = except BaseException: και επιτρέπεται μόνο τελευταίο (αλλιώς SyntaxError).
  • return μέσα στο try → φεύγουμε, το else δεν τρέχει, το finally τρέχει. return μέσα σε finally «καταπίνει» την εξαίρεση.
  • Εξαίρεση μέσα σε except → δεν την πιάνουν τα αδελφά except. Εσωτερικό try χωρίς ταίριασμα → η εξαίρεση ανεβαίνει στο εξωτερικό.

2.1Ιεραρχία εξαιρέσεων

  • BaseException → Exception → ArithmeticError (ZeroDivisionError, OverflowError) · LookupError (IndexError, KeyError) · ValueError · TypeError · AssertionError.
  • SystemExit, KeyboardInterrupt κρέμονται απευθείας από το BaseException → το except Exception δεν τα πιάνει.
  • Λίστα/λάθος θέση → IndexError. Λεξικό/λάθος κλειδί → KeyError. Κακό κείμενο στο int() → ValueError. Κακός τύπος → TypeError. Άγνωστο όνομα → NameError.
  • Το traceback δείχνει πάντα την πραγματική κλάση (το παιδί), ακόμα κι αν θα την έπιανε ο γονιός.

2.2raise · assert · δικές μας εξαιρέσεις

  • raise ValueError = raise ValueError(). raise "text" → TypeError. Σκέτο raise μέσα σε except → ξαναστέλνει την ίδια· έξω από except → RuntimeError.
  • Η εξαίρεση διαδίδεται: διακόπτει κάθε συνάρτηση στη διαδρομή, στη γραμμή της κλήσης, μέχρι να βρει except που ταιριάζει. Αν πιαστεί, το πρόγραμμα συνεχίζει (ο βρόχος προχωρά).
  • assert συνθήκη, "μήνυμα" → AssertionError αν ψευδής. Μήνυμα προαιρετικό. Πιάνεται από except Exception. Με python -O αγνοείται → όχι για έλεγχο εισόδου.
  • class MyError(Exception): pass → έτοιμη. Χωρίς γονιό (class MyError: pass) → TypeError στο raise. Ακολουθεί τους ίδιους κανόνες ιεραρχίας.

Τι τυπώνει; — πρώτα ψηφίζει η τάξη, μετά κλικ

01κλικ για απάντηση
from math import floor as f
print(f(-0.5), int(-0.5))
-1 0

floor → −∞, int → 0. Στους αρνητικούς διαφέρουν.

02κλικ για απάντηση
import random
random.seed(3)
x = random.choice("abc")
random.seed(3)
print(x == random.choice("abc"))
True

Ίδιο seed → ίδια ακολουθία.

03κλικ για απάντηση
# a.py
print("A", __name__)

# main.py
import a
import a
print("M", __name__)
A a
M __main__

Το module τρέχει μία φορά, με __name__ = "a". Μόνο το main έχει __main__.

04κλικ για απάντηση
try:
    print("x", end=" ")
    int("1")
except ValueError:
    print("e", end=" ")
else:
    print("o", end=" ")
finally:
    print("f")
x o f

Χωρίς εξαίρεση: try → else → finally. Το except παραλείπεται.

05κλικ για απάντηση
try:
    {}["a"]
except IndexError:
    print("I")
except LookupError:
    print("L")
L

Λεξικό → KeyError. Δεν είναι IndexError, αλλά είναι LookupError (γονιός).

06κλικ για απάντηση
def f():
    try:
        return 1
    finally:
        print("fin", end=" ")

print(f())
fin 1

Το finally τρέχει πριν «φύγει» το return.

07κλικ για απάντηση
x = 5
assert x > 10, "small"
print("ok")
AssertionError

Ψευδής συνθήκη → AssertionError: small. Το ok δεν τυπώνεται.

08κλικ για απάντηση
class E(Exception):
    pass

try:
    raise E
except Exception:
    print("E caught")
E caught

Παιδί του Exception → το πιάνει το except Exception. raise E χωρίς παρενθέσεις είναι έγκυρο.
